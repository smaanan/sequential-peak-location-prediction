# Sequential Peak Location Prediction

This repository contains the R code and supporting materials for the paper Sequential Peak-Location Prediction by Quantile Regression: Stabilization and Entry-Exit Intervals.

The project implements a quantile regression approach for estimating the location, amplitude, and spread of a peak in sequentially observed time series data.

It studies how the estimated peak location stabilizes over time, builds data driven entry-exit intervals, and evaluates the method through simulation studies and applications to COVID-19 case counts.
